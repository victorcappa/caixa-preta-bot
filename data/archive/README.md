# Malas legadas

`scene-zero-suitcases-legacy.js` preserva a configuração anterior das malas:

1. ordem fixa `2 → 3 → 1`;
2. Mala 2 com karaokê de Evidências;
3. Mala 3 com descrição do objeto pelo cheiro;
4. Mala 1 com glitch crescente, BIOS corrompida e blackout.

As falas, letras, durações e o banco antigo continuam em
`data/scene-zero-gincanas.js`. Os componentes de karaokê e BIOS e todos os
assets de áudio e vídeo também permanecem no projeto. A implementação completa
anterior está registrada no commit `d79e8be`.
