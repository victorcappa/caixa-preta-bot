> VISAO GERAL

Este projeto e um prototipo local para o espetaculo A Caixa Preta. Ele roda uma interface publica de conversa e um painel separado de operador, sincronizados em tempo real pelo servidor do Next.js.

PROJECAO PUBLICA

A tela principal fica em http://localhost:3000. E nela que o publico ve as mensagens e pode escrever para a Caixa Preta.

OPERATOR

O painel de controle fica em http://localhost:3000/operator e tambem pode ser aberto pelo botao OP na tela principal. Ele serve para registrar memorias, disparar falas orientadas e reiniciar a sessao.

> INSTALACAO

  1. Instale Node.js 20 ou superior.
  2. Instale as dependencias do projeto.
  3. Crie o arquivo .env.local com a chave da OpenAI.
  4. Rode o servidor local e abra as duas interfaces.
npm install

# .env.local
OPENAI_API_KEY=sua_chave_aqui
OPENAI_MODEL=gpt-5-mini

npm run dev

O arquivo .env.local nao deve ser commitado. O modelo padrao e gpt-5-mini; para testes locais de menor custo, use gpt-5-nano. O operator tambem permite alternar entre os dois durante a apresentacao.

> USO PRATICO NA PROJECAO

  1. Abra http://localhost:3000 no navegador que sera projetado.
  2. Espere a tela inicial terminar a entrada de texto.
  3. Digite uma pergunta ou provocacao no campo inferior.
  4. Pressione Enter e aguarde o status sair de PROCESSING.
  5. A resposta aparece na tela como texto digitado pela maquina.
PUBLICO > voce esta ouvindo a gente?
> resposta da Caixa Preta aparece aqui...

Na tela publica, o comando especial /reset limpa a conversa e volta para a tela inicial. Outros textos iniciados por barra sao recusados como comando desconhecido.

> COMO FUNCIONA O OPERATOR

O operator e um console de bastidor. Ele nao e para o publico: serve para alimentar o contexto da IA durante a apresentacao e para conduzir momentos especificos sem mostrar a instrucao original na projecao.

Alem de abrir /operator em outra aba, voce pode pressionar o botao OP abaixo do guia ?. Em telas largas, o terminal operador aparece ao lado do chatbot; em telas menores, ele entra como gaveta animada. Quando o Instagram embutido estiver visivel, arraste as divisorias entre chat, Instagram e operator para ajustar a composicao de palco. O tamanho fica salvo no navegador.

MEMORY BUFFER

Mostra as ultimas memorias registradas pelo operador. Essas observacoes entram nas proximas chamadas como contexto silencioso da apresentacao, classificado entre RECENT, RELEVANT e AVAILABLE.

STATUS

A barra superior indica conexao, modelo selecionado, quantidade de memorias, mensagens, variaveis e se a base local de conhecimento foi carregada. O seletor MODEL muda as proximas chamadas da Caixa Preta sem reiniciar o servidor.

> COMANDOS

/memory texto

Guarda uma observacao sobre a apresentacao atual. Use para fatos que devem influenciar respostas futuras, sem forcar uma fala imediata. Memoria nao e conteudo para recitar: a Caixa Preta pode usar, ignorar, guardar para callback ou deixar a observacao alterar ritmo, tom e decisao. 

/memory entrou uma pessoa atrasada de blusa listrada
/say orientacao

Pede uma fala da Caixa Preta a partir de uma instrucao do operador. A instrucao nao aparece literalmente para o publico; a IA transforma a orientacao em fala. 

/say faca um comentario curto indicando que agora podemos comecar
/model modelo

Escolhe o modelo usado nas proximas respostas. Use gpt-5-mini para mais corpo e personalidade, ou gpt-5-nano para testes de menor custo. O mesmo controle aparece como seletor no topo do operator. 

/model gpt-5-nano
/phone request participante tipo privacidade

Prepara uma solicitacao segura de projecao de celular. Isso nao projeta conteudo privado sozinho: cria um pedido pendente para confirmacao humana. Use /phone approve para aprovar e /phone hide para cortar imediatamente. O botao HIDE PHONE no operator executa o corte sem confirmacao extra. 

/phone request Victor instagram_search high
/phone approve
/phone hide
/instagram abrir

Abre o Instagram real em Chromium controlado pelo Playwright e mostra um painel lateral embutido, mantendo o chat visivel ao lado, sem analisar a tela nem executar acao social. Quando existe uma conta lembrada, pressiona Continue, aguarda o campo seguinte e preenche a senha do arquivo local. O formulario classico permanece como fallback; captcha, checkpoint e 2FA continuam manuais. O botao X fecha apenas o painel; a sessao fica em .runtime/instagram-profile/. 

/instagram abrir
/instagram follow cappavictor
/game [tipo|stop|replace|secret]

Controla jogos do HOST sem expor o comando na projecao. Se ja houver jogo ativo, /game nao empilha outro: use /game stop ou /game replace tipo. Em Maria Antonieta com a Caixa adivinhando, /game secret texto guarda o segredo no servidor/operator sem enviar esse segredo para o modelo. 

/game maria
/game secret Anitta
/game mestre
/game cards
/game verdade-ou-bolo
/game stop
/game replace forca

Em Verdade ou Bolo?, chat e jogo ficam lado a lado. A rodada mostra primeiro o frame inicial pausado e so entao abre 10 segundos de voto. Ao chegar a zero, aparecem imediatamente resposta, acerto ou erro e placar; sem voto, aparece SEM VOTO e a rodada conta como erro. REVELAR RESPOSTA antecipa essa mesma resolucao durante a votacao. O video pode ser tocado separadamente depois da revelacao. Depois que a Caixa termina de digitar o comentario da resposta, o jogo avanca automaticamente para a proxima rodada ou para o resultado final.

/mala

Entra no modo MALAS e gera uma transicao contextual na projecao sem revelar o comando tecnico. Tambem inicia o controlador das tres malas e deixa o estado aguardando escolha publica. /malas tambem funciona como alias. 

/mala
/mala abort
/mala reset
/mala 1
/mala 2
/mala 3
/mala next
/mala win
/mala lose
/reset

Apaga conversa, memorias e variaveis da sessao atual. Use antes de uma nova passagem, ensaio ou apresentacao. 

/reset

No operator, texto sem barra retorna COMMAND REQUIRED. Comandos nao reconhecidos retornam UNKNOWN COMMAND.

> SISTEMA DAS MALAS

O controlador fica em lib/suitcases/SuitcaseDirector.js. Ele separa interpretacao da entrada, estado da experiencia, logica dos jogos, acoes visuais e debug. A fala continua vindo da chamada normal da Caixa Preta; o modelo recebe o estado estruturado e improvisa sem virar menu.

MALA 1 / VERDADE OU BOLO

Reutiliza o jogo estruturado verdade_ou_bolo do GameDirector. O jogo entra direto na primeira rodada e mostra o frame inicial pausado antes de iniciar os 10 segundos de decisao. O video pode ser tocado separadamente; tanto o fim do timer quanto REVELAR exibem imediatamente resposta, resultado e placar. O operador controla o timing e avanca diretamente com PROXIMA RODADA. A Caixa improvisa entrada, comentarios e provocacoes com o contexto atual, e essas falas aparecem no chat ao lado da tela do jogo.

MALA 2 / GINCANA

Sorteia sem repeticao durante a sessao a partir de data/scene-zero-gincanas.js. Cada tarefa configura instrucao, dificuldade, observacoes e faixa de duracao limitada a 60–120 segundos. O sistema apresenta literalmente uma ordem fechada do banco, sem deixar objeto ou criterio para o participante escolher e sem permitir reformulacao pelo modelo. O timer aparece na projecao; somente ACAO CONCLUIDA ou FALHOU / TEMPO ESGOTADO pede ao modelo o comentario posterior.

MALA 3 / GLITCH + INSTAGRAM

O operador inicia a mala, dosa NORMAL, GLITCH 1–4 e COLAPSO, e abre manualmente Robson ou Janaina. O mesmo navegador real inspeciona ate dez posts por perfil. Cada comentario gerado aparece em preview e so e publicado pelo botao explicito de envio; posts comentados nao podem receber um segundo envio na sessao.

Ao iniciar uma mala diferente, a mala anterior e interrompida: jogo ativo, timer da gincana, rotina de Instagram e glitch associado nao continuam em paralelo. 

npm run test:suitcases

A troca MALA 1 → MALA 2 → MALA 3 nunca e automatica. Os comandos /mala continuam disponiveis para o SuitcaseDirector legado e recuperacao; a dramaturgia atual e operada nos tres cartoes da Cena 0.

> CONTEUDO DA IA

A resposta da Caixa Preta nasce de uma montagem de contexto. O servidor junta personalidade, regras dramaturgicas, exemplos, conhecimento local, observacoes silenciosas da apresentacao, historico recente e a orientacao do operador quando existe.

As observacoes de /memory sao fatos de contexto, nao mensagens do publico. Elas nao precisam ser reconhecidas nem usadas imediatamente. O comportamento desejado e memoria como percepcao: observar, interpretar, decidir e agir.

No modo HOST, conversa tambem e gameplay. conversationRun e um periodo de 2 a 8 turnos em que a Caixa Preta pode conversar, comentar, implicar, fazer follow-up, usar memoria, fazer piada ou mudar de assunto sem iniciar jogo, ponto, cargo, voto, gesto ou countdown.

O repertorio de jogos e microdinamicas fica em lib/host/games.js. Quando houver GAME START, o GameDirector prioriza jogos reconheciveis e stateful: Maria Antonieta / Quem Sou Eu, Mestre Mandou, Cards-style, Forca, desenho, Pictionary em times, Adivinhe a Regra, Sim/Nao proibidos, Palavra Proibida, charadas, quiz, equipes e text adventure. Pontos falsos, cargos, inventario, votacoes abstratas e tarefas arbitrarias sao microdinamicas: podem aparecer como piada ou dentro de jogos, mas nao substituem jogo real.

A mesma biblioteca inclui phone_games: celular como objeto cenico, evidencia, algoritmo pessoal, lanterna, nota, camera, calculadora ou timer. Participacao com celular e sempre voluntaria. Buscas, fotos, Instagram search, conteudo pessoal ou qualquer projecao exigem confirmacao humana no operator. Se houver recusa, a Caixa Preta deve reagir com personalidade e pode voltar para conversa, mudar de assunto ou abrir outro jogo somente se houver oportunidade real.

Privacy ladder: low para numeros e metadados; medium para ultimo emoji, ultima musica, bio propria ou evidencia escolhida; high para buscas, fotos, conteudo pessoal, Instagram search ou projecao. high exige requiresOperatorApproval.

> ROTEIRO DE OPERACAO

  1. Antes do ensaio, rode npm run dev.
  2. Abra a projecao em tela cheia em localhost:3000.
  3. Abra o operator em outro navegador, monitor ou aba.
  4. Use /reset para comecar limpo.
  5. Durante a cena, use /memory para registrar acontecimentos reais como contexto silencioso.
  6. Use /say quando precisar que a Caixa Preta intervenha agora.
  7. Use o seletor MODEL ou /model para alternar entre gpt-5-mini e gpt-5-nano.
  8. Em jogos com celular, use /phone approve somente depois de confirmacao humana; use HIDE PHONE ou /phone hide para cortar imediatamente.
  9. Use /mala quando a cena deve entrar no modo MALAS.
  10. Quando um evento COUNTDOWN termina, a Caixa Preta continua sozinha a partir do fim da contagem. A IA so pode gerar countdown quando a fala publica contem duracao explicita em segundos.
  11. Ao final, use /reset se a proxima sessao nao deve herdar nada.

> PROBLEMAS COMUNS

  • OPENAI_API_KEY ausente: confira se .env.local existe na raiz e reinicie o servidor.
  • DISCONNECTED: verifique se npm run dev continua rodando e recarregue a pagina.
  • A resposta demora: espere o estado PROCESSING. Se persistir, veja o terminal do servidor.
  • Conteudo antigo reaparece: use /reset no operator para limpar conversa, memorias e variaveis.
